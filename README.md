# HackerRank solutions

Folder structure:

- `JavaScript/` — JavaScript solution files, one per problem (include problem URL in a top-line comment).

Run a solution locally by piping input, for example:

```
node JavaScript/accountTranscation.js < input.txt
```

Git workflow (example):

```
git init
git add .
git commit -m "Initial commit: add HackerRank solutions"
git branch -M main
# add remote then:
git push -u origin main
```
